# 레버가치 원복 계산기 + 원복 법당 — 공개 배포 가이드

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 3배 레버리지 원복 계산기 (KORU·SOXL) |
| `room3d.html` | 3D 원복 객장 (three.js, `vendor/` 폴더 필요) — 2D와 같은 방에서 서로 보임 |
| `vendor/three.module.min.js` | 3D 그래픽 라이브러리 (폴더째 업로드) |
| `room.html` | 원복 법당 — 닉네임·평단 입장, 캐릭터·말풍선, 이모티콘·몸짓·목탁·채팅 |
| `calc-core.js` | 계산 수식 (테스트 가능한 순수 로직) |
| `live.js` | 시세 공급 + 실시간 방 연결 (Firebase / 미리보기) |
| `config.js` | **여기에 키 2개만 넣으면 됨** |
| `database.rules.json` | Firebase 보안 규칙 (그대로 붙여 넣기) |
| `price_pusher.py` | (선택) 노트북에서 프리·애프터마켓 시세 송신 |

설정 없이 올려도 계산기는 완전히 동작합니다(현재가 직접 입력). 법당은 '같은 브라우저 탭끼리'만 연결되는 미리보기로 열립니다.

## 1단계 — 누구나 볼 수 있게 올리기 (GitHub Pages, 무료)
1. github.com 로그인 → 오른쪽 위 **+ → New repository** → 이름 예: `wonbok` → **Public** → Create
2. **Add file → Upload files** → 이 폴더의 파일과 **`vendor` 폴더까지** 전부 끌어다 놓기 → Commit
3. **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save
4. 1~2분 뒤 `https://<깃허브아이디>.github.io/wonbok/` 로 누구나 접속 (법당: `.../room.html`)

> Netlify Drop(app.netlify.com/drop)에 폴더를 끌어다 놓는 방법도 됩니다.

## 2단계 — 법당을 모두가 같이 쓰게 (Firebase, 무료 Spark 요금제)
1. console.firebase.google.com → **프로젝트 추가** (애널리틱스 꺼도 됨)
2. 왼쪽 **빌드 → Authentication → 시작하기 → 로그인 방법 → 익명** 사용 설정
3. **빌드 → Realtime Database → 데이터베이스 만들기** → 위치 `asia-southeast1(싱가포르)` → *잠금 모드*로 시작
4. Realtime Database **규칙** 탭 → `database.rules.json` 내용을 통째로 붙여 넣고 **게시**
5. **프로젝트 설정(톱니) → 내 앱 → 웹(</>)** 앱 등록 → 나오는 `firebaseConfig` 값을 `config.js`의 `firebase:`에 붙여 넣기
   (`databaseURL` 이 꼭 있어야 합니다. 없으면 Realtime Database 화면 상단 주소를 복사)
6. **Authentication → 설정 → 승인된 도메인**에 `<아이디>.github.io` 추가
7. 수정한 `config.js`를 GitHub에 다시 업로드

> Firebase 웹 apiKey는 공개돼도 되는 값입니다(보안은 4번 규칙이 담당).

## 3단계 — 시세 자동 반영 (Finnhub 무료 키)
1. finnhub.io → 무료 가입 → Dashboard의 API Key 복사 → `config.js`의 `finnhubKey`에 붙여 넣기
2. 접속자 중 **한 명(대표)** 만 15초마다 조회해 DB에 쓰고, 나머지는 DB를 구독합니다 → 접속자가 많아도 무료 한도(분당 60회) 안쪽
3. 브라우저 코드에 들어간 키는 누구나 볼 수 있습니다. 무료 키라 금전 피해는 없지만, 남용되면 Finnhub에서 키를 재발급하세요.

### 지수 시세판 (나스닥·코스피·필라델피아 반도체·원/달러)
- Finnhub 무료 키로는 지수 자체가 안 나와서, 시세판에 **대용 ETF**(나스닥→QQQ, 한국→EWY, 반도체→SOXX)를 "대용" 표시와 달러 가격으로 보여 줍니다. 대용 값은 계산기의 '현재 지수'에 자동으로 넣지 않습니다.
- 진짜 지수값(나스닥 ^IXIC, 코스피 ^KS11, 필라델피아 반도체 ^SOX, 원/달러)은 아래 송신기를 돌리면 올라오고, 이때 계산기의 '현재 코스피/SOX'도 자동으로 채워집니다.

### 프리·애프터마켓까지 확실히 반영하려면 (선택)
Finnhub 무료 시세가 연장 거래를 얼마나 반영하는지는 보장되지 않습니다. 노트북에서 `price_pusher.py` 를 돌리면 yfinance(프리·애프터 포함) 값을 30초마다 올리고, 브라우저들은 이 값을 우선 사용합니다.
```
pip install yfinance requests
python price_pusher.py      # 파일 위쪽 API_KEY, DB_URL 두 줄만 채우기
```
**국내 증권사 '데이마켓(주간거래)' 시세는 무료 공개 소스가 없어 반영되지 않습니다.** 그 시간대에는 직전 체결가와 시각을 그대로 표시합니다.

## 법당 기능 (원복 법당 · 개미 객장)
- **자유 이동**: 1600×900 객장 월드를 걸어 다닙니다(내 캐릭터를 카메라가 따라감, 오른쪽 위 미니맵). 방향키/WASD 또는 화면 ◀▲▶▼ 버튼(누르고 있기), 바닥을 누르면 그곳으로 이동, 빈 방석을 누르면 가서 앉기. Shift(또는 방향 버튼 두 번 톡)로 달리기, Space로 점프, 🪑앉기/🧍일어나기.
- **상호작용 오브젝트**: 시주함·운세 전광판·대형 목탁·투표 게시판·108배 방석 가까이 가면 「E 상호작용」 말풍선 → E 키 또는 ✋상호작용 버튼. 오브젝트를 누르면 걸어가서 바로 사용.
- **공덕 포인트·등급**: 절하기 +3, 목탁 +1, 시주 +5, 물타기 +2, 1분 머무름 +1, 108배 완주 +108(같은 동작 1초 쿨타임). 개미 → 불개미(50) → 일개미반장(150) → 슈퍼개미(400) → 큰손(1000) → 세력(3000) → 원복 성불(10000). 레벨 업 시 모두에게 폭죽.
- **108배 챌린지**: 진행 링 표시, 완주하면 칭호 「108배 완주」와 금빛 효과.
- **시주함**: 동전이 날아가 들어가고, 방 전체 누적 시주 수가 공유됩니다.
- **오늘의 운세**: 전광판(또는 운세 오브젝트)을 누르면 하루 동안 같은 점괘. 재미용.
- **내일 방향 투표**: KORU/SOXL 상승·하락 투표, 날짜(KST)마다 새로 시작. 재미용.
- **시황 날씨**: 전광판의 KORU·SOXL(3배 ETF 자체) 전일 대비 등락률 평균이 +10% 이상이면 파티 모드(폭죽·금가루), −10% 이하면 우울 모드(비·먹구름·번개, 화면 어두워지고 개미들이 고개 숙임). 전일 종가가 없으면 잔잔.
- **머리띠 꾸미기**: 내 정보에서 원복/존버/물타기, 등급이 오르면 손절X·풀매수·상한가·가즈아.
- **랭킹**: 지금 객장에 있는 사람들의 공덕 순위.
- 효과음은 모두 🔔 소리 버튼으로 끌 수 있습니다. 공덕 점수는 각자 브라우저에 저장되는 재미용 값입니다.

## 방 나누기
`room.html?room=koru`, `room.html?room=soxl` 처럼 주소 뒤에 방 이름을 붙이면 별도 법당이 됩니다(영문 소문자·숫자·하이픈 24자 이내).

## 운영 시 참고
- 채팅은 방마다 최근 50개만 화면에 표시됩니다. 오래된 기록은 Firebase 콘솔에서 `rooms/<방>/chat` 을 지우면 됩니다.
- 욕설·도배 필터는 없습니다(1.5초당 1개 제한, 120자 제한만 있음). 공개 운영 시 콘솔에서 주기적으로 확인하세요.
- 수익률·목표지수는 입력값과 표시 시세 기준 참고값이며 투자 조언이 아닙니다.
